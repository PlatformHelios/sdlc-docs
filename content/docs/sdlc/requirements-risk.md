## Objectives

Before code generation begins:

- Define business requirements
- Identify regulatory requirements
- Identify security requirements
- Classify data sensitivity

## Deliverables

- Business Requirements Document
- Risk Assessment
- Data Classification
- Architecture Diagram

## System classification

Every system is categorized by criticality:

| Classification | Examples |
|---|---|
| **Critical** | Online banking, wire transfer systems |
| **High** | Loan servicing, treasury |
| **Moderate** | Internal applications |
| **Low** | Department utilities |

The classification determines:

- Testing rigor
- Approval requirements
- Red-team frequency
- Pen-testing schedule
