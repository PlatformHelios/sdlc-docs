## Static testing (SAST)

Analyze:

- Source code
- Security flaws
- Coding violations

Examples: SonarQube, Checkmarx, Veracode.

## Dynamic testing (DAST)

Test:

- Running applications
- Web APIs
- Authentication

Examples: Burp Suite, OWASP ZAP.
