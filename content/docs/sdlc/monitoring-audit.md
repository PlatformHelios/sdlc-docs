## Continuous monitoring

Monitor:

- Errors
- Security events
- User activity
- AI interactions

## Audit evidence

Retain:

- Requirements
- Design approvals
- Code reviews
- Test results
- Security assessments
- Deployment records

## Retention

Typically **7 years**, or according to institutional policy.
