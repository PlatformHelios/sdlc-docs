---
title: AI Governance Controls
weight: 20
---

Controls that apply across the lifecycle whenever AI is used in development.

| Control | Requirement |
|---|---|
| **Approved models** | Only sanctioned AI platforms |
| **Prompt logging** | Maintain prompt history |
| **Code attribution** | Track AI-generated code |
| **Model risk review** | Assess AI development tools |
| **Security review** | Validate generated code |
| **Human approval** | Mandatory before production |
| **AI red teaming** | Test for AI-specific vulnerabilities |
| **Audit record** | Maintain complete traceability |
