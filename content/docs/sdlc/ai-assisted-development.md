Applies when AI tools are used in development.

## AI development tools

Developers may use tools such as:

- Cursor
- GitHub Copilot
- Claude Code
- Internal LLMs

## Required controls

### Approved models only

| Approved | Not approved |
|---|---|
| Enterprise LLM | Public consumer AI |
| Private LLM | Unauthorized models |
| Copilot Enterprise | |

### Prompt logging

Maintain:

- Prompts
- Generated code
- Developer modifications

### Audit trail

The audit trail should include:

- Developer
- AI-generated component
- Review date
- Approver
- Deployment version
