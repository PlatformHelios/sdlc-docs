## Human review required

{{< callout type="warning" >}}
Code cannot bypass peer review, regardless of whether it was written by a person or generated by AI.
{{< /callout >}}

## Required reviews

### Functional review

- Requirements met
- Logic accuracy
- Error handling

### Security review

- Authentication controls
- Authorization controls
- Secrets management
- Input validation

### Compliance review

- Regulatory requirements
- Audit requirements
- Logging requirements
