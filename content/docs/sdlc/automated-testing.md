## Unit testing

**Target:** 80–90% code coverage

Focus:

- Business logic
- Data validation
- Error handling

## Integration testing

Validate:

- API interactions
- Database connectivity
- Third-party integrations

## Regression testing

Regression testing is a critical requirement for AI-generated software. Every release triggers:

- Automated regression suite
- Performance baseline validation
- Security control validation
