## Application pen testing schedule

Frequency is driven by [system classification](../requirements-risk#system-classification):

| Classification | Required frequency |
|---|---|
| **Critical** | Every major release |
| **High** | Minimum annually |
| **Moderate** | Risk-based schedule |

## Test coverage

Testing includes:

- Authentication bypass
- Authorization bypass
- Injection attacks
- Session hijacking
- API testing
